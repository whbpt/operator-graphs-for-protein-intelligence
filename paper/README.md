# Paper build

The research is now split into two manuscripts:

- `protein_operator_graph_framework.tex` is the authoritative theory framework.
- `ternary_msa_reconstruction.tex` is the PRL/PRX-direction manuscript on three-state relation
  gates at both family-MSA and ESM-style single-sequence scales.

`theory_main.tex` is a compatibility entry point for the framework manuscript. `main.tex` is the
longer empirical research log; its downstream architecture conclusions are provisional because an
independent review found a target-construction alias and a teacher/student gauge mismatch.

The paper is an evolving research draft. Build from this directory with:

```bash
sh ../tools/tectonic/build.sh main.tex
sh ../tools/tectonic/build.sh protein_operator_graph_framework.tex
sh ../tools/tectonic/build.sh ternary_msa_reconstruction.tex
```

Reported pilot values are generated by:

```bash
# Run from the project root.
PYTHONPATH=src TORCH_HOME=data/raw/torch .venv/bin/python \
  experiments/train_3cnba_factor_head.py \
  --alignment data/raw/3CNBA/3CNBA.aln \
  --distances data/raw/3CNBA/3CNBA.dist \
  --reference data/raw/3CNBA/3CNBA.mtx_ref \
  --jacobian results/3cnba_categorical_compression/categorical_jacobian.npz \
  --output results/3cnba_factor_head_rank32_gated_nocorr \
  --rank 32 --steps 2000 --sampled-pairs 2048 \
  --sparse-weight 0.01 --strength-weight 0.5 --seed 29
```
