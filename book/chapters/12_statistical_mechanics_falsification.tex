The corresponding protein audits should retain the book's typed coordinates.  A random-energy
comparison tests whether low-order operator mass exceeds a landscape with no reusable positional
structure.  A cavity comparison tests a message approximation to a declared sequence law;
endpoint exclusion separately tests invariance of support construction.  A dynamical-response
comparison tests propagation through layers or recurrent time, then asks whether that internal
transport predicts the externally audited categorical operator.

Each label combines an object, an ensemble, a limiting or replication protocol, and an observation
that a simpler null fails to reproduce.  Reporting these four fields
turns statistical-mechanics language into a falsifiable extension of the operator audit.
